FLUJO AUTOMATIZADO EN GITHUB

Cómo subir cambios y publicar una nueva versión

.github/workflows/
01

Subir código y actualizar Changelog

Registra tus cambios en CHANGELOG.md (y en app/build.gradle.kts si incrementas versionCode / versionName) y súbelos a GitHub:

git add .
git commit -m "docs: actualizar changelog y página de releases"
git push origin main
02

Publicar tag para compilar APK, AAB y Release

Al subir una etiqueta v*, GitHub Actions ejecuta pruebas, firma el APK/AAB, extrae tus notas de CHANGELOG.md y crea la Release automáticamente:

git tag -a v1.1 -m "Flora v1.1"
git push origin v1.1
03

Activar esta página en GitHub Pages

En tu repositorio ve a Settings → Pages y en Build and deployment → Source elige GitHub Actions. Cada push a main o nueva Release actualizará esta web automáticamente.
