📋 Resumen del Sistema
• Proyecto: Sistema POS y ERP

• Framework: React con TypeScript, TailwindCSS, rust con wasm, base de datos sqlite, herramientas como lo es vercel para el frontend y cloudflare workers con wasm para el backend

• Modelo: Gemini 3 Flash

• Objetivo: Crear un sistema POS y ERP para pequeñas y medianas empresas, Sistema intuitivo y facil de usar, con un diseño moderno y limpio, con un rendimiento optimo y escalable, con un precio accesible y competitivo, con un soporte tecnico de calidad y una garantia de satisfaccion total.
